    六耀の決闘

    運命の数字を、
    最善の一手に。

    1. 異なる5体を選び、最初の前衛を決める

      HPはキャラ別です。相手の5体すべてを戦闘不能にすると勝利。交代してもHPと結界はそのキャラに残ります。

    2. 数字 → 出場キャラ → 通常技

      1〜6が等確率で確定した後、生存キャラを選びます。選んだ数字の通常技を使うと、そのキャラが前衛に残って次の敵の攻撃を受けます。控えは攻撃されません。選び直しで数字は変わりません。

    3. 固有スキルは数字確定後、通常技の前に1回

      チームで自分の1ターンに1回まで。スキルだけでは交代しません。攻撃強化はそのターンに使う通常技の攻撃だけに有効。回復先・結界の対象は生存している味方1体を選びます。控えも選べますが、戦闘不能は復活しません。

    4. 待ち時間は自分のターン開始で1減る

      待ち時間3のスキルを1ターン目に使うと2ターン目に残り2、3ターン目に残り1、4ターン目に再使用可能。結界は対象が受ける次の防御可能なダメージ1回を半減。交代しても他キャラに移らず、消費まで継続し、重複できません。

    5. 前衛が倒れたら、後任を選ぶ

      後任選択には攻撃・ターン消費はありません。スキルで敵前衛を倒した場合も後任を選んでから、同じ数字で通常技を選べます。先攻はあなた。CPUにも同じルールです。

    6. 属性有利は通常技だけ1.05倍

      水→火、火→自然、自然→水、聖光→呪闇、呪闇→聖光。それ以外は1倍で、不利による減衰はありません。基礎ダメージ→攻撃強化→属性→防御の順に計算し、最後に四捨五入します。固有スキル・固定ダメージ・回復には属性倍率を適用しません。副属性は表示・分類のみです。

    16巡目から回復疲労で回復量が1巡につき10ポイント減少（最低25％、最終回復量切り捨て）。前衛・控えに同条件です。通常技とスキルの回復量表示はこの補正を受けます。再戦で全員のHP・待ち時間・一時効果を初期化します。
