# 六耀の決闘 — 固定チーム・固有スキル版

日本語の1人用ファンタジーバトル。戦闘前に8体から異なる5体を選び、固定チームでCPUと対戦します。数字を先に出し、任意で固有スキルを1つ使った後、その数字に合う通常技を選びます。

## Macで遊ぶ（追加ソフト・サーバー・通信不要）

`downloads/rokuyo-duel.html` を保存し、Safariの「ファイル」→「ファイルを開く」で選択してください。HTML・CSS・JavaScriptを内蔵し、外部フォントは読み込みません。Macの日本語フォントを使用します。

## 調整する場所

- `src/game.js` の `CARDS`：キャラクター名、色、出目1〜6順の通常技。`damage` が攻撃、`heal` が回復。
- 同ファイルの `SKILLS`：`CARDS` と同じ順の固有スキル。名前、説明、`cooldown`（待ち時間）、`damage`、`heal`、`multiplier`、`bonus`、`shield`、`bypass`、`reroll` で設定。
- 同ファイルの `RULES`：共有HP、チーム人数（`handSize`）。人数やHPを変更する場合は画面・説明の固定表示も更新してください。
- `startTurn`：本人のターン開始時だけ待ち時間を1減らし、スキル使用権を復活。初回は減算せず全員0で開始。
- `useSkill` と `useCard`：操作制限、ダメージ、回復、勝敗。攻撃強化はそのターンの通常技のみ。結界は防御可能なダメージ1回まで継続。
- `cpuChoice` と `cpuSkillChoice`：CPUの通常技・スキル評価。体力が少ないと回復を重視し、即勝利、攻撃強化、結界、振り直しの期待値も比較。
- `src/app.js`：画面操作、編成、ログ、演出と待機時間。
- `style.css`：見た目とスマートフォン向けレイアウト。

ソース変更後、`python3 scripts/bundle.py` で単一HTMLを再生成します。配布用HTMLの利用者にはPythonもNode.jsも不要です。

## 開発・確認

```sh
npm test
npm start
```

テストはNode.js標準のテスト機能を使用。開発サーバーのみPython 3を使用し、ポート3000で配信します。

テストは8体×6出目の対応、固定チーム、待ち時間とターンの所有者、1ターン1スキル、振り直し、HP上限、結界と防御無視、強化と回復の分離、CPUの判断、勝敗、再戦初期化を検証します。

## HP300版のバランス

最大・初期HPは両側300。通常技の攻撃値は維持し、通常技の回復を旧版の1.3倍（四捨五入）にしています。回復スキルは月泉35、翠樹20、潮16に調整しました。待ち時間・固定チーム・攻撃強化は維持しています。

回復による長期停滞を避けるため、16巡目から「回復疲労」を適用します。回復倍率は90％から1巡につき10ポイント下がり、最低25％。両側の通常技・スキルに同条件で適用し、最終回復量は切り捨てです。画面には倍率と補正後の通常技回復量を表示します。再戦で解除されます。

`node scripts/balance.mjs` で再現可能な1,500戦を実行します。各戦はシード1〜500で異なる5体をランダム編成し、出目もシード乱数を使用。CPUは実ゲームと同じ判断です。プレイヤーは「CPUと同じバランス型」「通常技は攻撃優先」「通常技は回復優先」の3方針で各500戦。スキル判断は全方針でCPUと共通です。人間のプレイ時間・Safari実機試験ではありません。

結果は `reports/balance.json`。平均プレイヤーターン数はバランス型12.51、攻撃優先10.68、回復優先21.19。全試合決着し、最長31ターンでした。バランス型でも6〜24ターンと幅があり、全試合が10〜15ターンに収まる保証はありません。双方が意図的に攻撃しない遊び方を含む、全方策での終了保証もありません。

## Web公開用

`python3 scripts/bundle.py` はダウンロード版と同内容の `docs/index.html` も生成します。外部ライブラリ、外部フォント、APIキー、サーバー側処理はありません。静的ホスティングに `docs` の内容をアップロードできます。初回は独自ドメインや有料プランを申し込む必要はありません。

GitHub Pagesを利用できる場合、リポジトリの Settings → Pages → Build and deployment → Deploy from a branch で、コードを保存したブランチと `/docs` を選びます。非公開リポジトリでは契約条件により利用できないため、有料プランの申し込みやリポジトリ公開設定への変更は行わず、静的サイトの直接アップロードを利用してください。

直接アップロードは、Cloudflare Pagesの無料プランなどで `docs/index.html` を含むZIPをアップロードします。URLが発行されたら、そのURLでゲームを開けます。サイトはURLを知る第三者もアクセスでき、URLはアクセス制限や秘密保持の仕組みにはなりません。画面とJavaScriptは閲覧・保存できます。チームと戦闘状態は各ブラウザのメモリー内だけで処理し、ログイン・個人情報送信・オンライン対戦はありません。
